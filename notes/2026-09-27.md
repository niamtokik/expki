## Erlang form to Erlang Term conversion

```elixir
  # erl_form converter
  def token({:dot, _}), do: ~c"."
  def token({x, _}) when is_atom(x), do: :erlang.atom_to_list(x)
  def token({:var, _, x}), do: :erlang.atom_to_list(x)
  def token({:char, _, c}), do: :io_lib.write_char(c)
  def token({:string, _, s}), do: :io_lib.write_string(s)
  def token({:atom, _, a}), do: :io_lib.write_atom(a)
  def token({_, _, x}), do: :io_lib.format("~w", [x])

  def tokens_to_charlist([], buffer) do
    # convert the buffer into
    expression = buffer
      |> Enum.reverse
      |> List.flatten

    with {:ok, tokens, _} <- :erl_scan.string(expression),
        {:ok, term} <- :erl_parse.parse_term(tokens)
    do
      {:ok, term}
    end
  end
  def tokens_to_charlist([token|tokens], buffer) do
    tokens_to_charlist(tokens, [token(token)|buffer])
  end
```

Finally, a module called `Expki.PublicKeyMacros` as been
created to deal with Erlang macros (`-define`). The idea to
use a function to map the key/value of the macros. This
module is imported in `Expki.PublicKey` offering all the
required functions to deal with macros.
