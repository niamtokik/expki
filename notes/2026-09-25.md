## Record Converter

An Elixir module called [`Record`](https://elixir.hexdocs.pm/Record.html) has been created to deal with
[Erlang records](https://www.erlang.org/doc/system/ref_man_records.html). Unfortunately, it seems
those generated records can't use name starting with an uppercase character. Probably because
the [macro generate a function](https://github.com/elixir-lang/elixir/blob/v1.20.4/lib/elixir/lib/record.ex#L262), and
I don't think function in Elixir can start with such letters. The problem is most of the records
used in the `public_key` module are starting with an uppercase letter!

Let have a look on alternative solutions then:

* continue to use raw tuples, but this is not really stable and
  can break the implementation if some version of the module
  change a record (argument position for example)

* re-implement the `Record` Elixir module and try to find a way to
  support the record name with uppercase letters, but I don't think
  it will be possible to achieve that easily, because the `Record`
  module creates functions.

* generate a module for each record, exporting functions to check,
  match, convert the record in different formats. If we enable all
  records, it will be 157 new modules created. It also means macros
  are required somewhere to avoid code deduplication. It could also
  be a good idea to create struct and types.
