One thing I don't understand is the format used for the
macros, it looks like they are tokens, but it does not
fit with what I know. See below an example of a tuple
contianing 7 integers:

```elixir
[
  none: {:none,
   [
     {:"{", 1131},
     {:integer, 1131, 1},
     {:",", 1131},
     {:integer, 1131, 2},
     {:",", 1131},
     {:integer, 1131, 840},
     {:",", 1131},
     {:integer, 1131, 113549},
     {:",", 1131},
     {:integer, 1131, 1},
     {:",", 1131},
     {:integer, 1131, 7},
     {:",", 1131},
     {:integer, 1131, 6},
     {:"}", 1131}
   ]}
]
```

This format is the one used by [`io:scan_erl_form/X`](https://www.erlang.org/doc/apps/stdlib/io.html#scan_erl_form/1).
I assume the function charge to expand the macro (inject the code into the source file)
is `:epp.token_src` and `:epp.stringify`. Based on the comment, this function is not
compatible wiht `erl_scan:text`. So, to convert the data present in the macros,
one will need to reimplement those functions.

see also: https://erlang.org/documentation/doc-7.0/erts-7.0/doc/html/absform.html
