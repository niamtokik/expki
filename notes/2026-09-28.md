## Validity

The [validity attribute](https://www.rfc-editor.org/info/rfc3280/#section-4.1.2.5) is using yet another datetime format
called [generalized time](https://en.wikipedia.org/wiki/GeneralizedTime). Based on these specs,
the format should look like `%y%m%d%H%M%SZ`

```console
$ date +%y%m%d%H%M%SZ
260928073530Z
```

The validity must be checked first

in the certificates table. If it becomes hard to manage, another
table will be created to store them.

## Keys

When generating a key with openssl x509, the private key
is encoded in DER, when using the generate function via
`public_key` module, it is encoded in PEM.
